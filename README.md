## 🧬 การสกัด 10 คุณลักษณะทางกายภาพ (Feature Extraction)

เพื่อจำแนกกลุ่มใบหน้าได้อย่างเป็นรูปธรรม ระบบจะแปลงภาพใบหน้าแต่ละคนเป็น Grayscale ขนาด $140 \times 180$ พิกเซล และสกัดเวกเตอร์คุณลักษณะ 10 มิติจากเมทริกซ์ภาพโดยตรง:

1. **Optical Density & Frame Gradient (F1):** วัดความต่างแสงและค่าคอนทราสต์บริเวณกรอบดวงตา (จำแนกบุคคลสวมแว่นตา)
2. **Follicular Forehead Gradient (F2):** วัดความคมชัดและการเปลี่ยนแปลงของเกรเดียนต์บริเวณไรผมหน้าผาก (ตรวจจับผมหน้าม้า)
3. **Structural Jawline Morphometry (F3):** วิเคราะห์มิติสัณฐานวิทยาของแนวกรามและคาง (สะท้อนโครงสร้างใบหน้า)
4. **Eyebrow Contrast & Density (F4):** ความหนาแน่นและความเข้มเฉลี่ยของแนวคิ้ว
5. **Global Luminance (F5):** ระดับความสว่างเฉลี่ยของพื้นผิวใบหน้าโดยรวม
6. **Bilateral Symmetry (F6):** ความสมมาตรของใบหน้าระหว่างซีกซ้ายและซีกขวา
7. **Midface Textural Variance (F7):** ความแปรปรวนของพื้นผิวส่วนกลางใบหน้าและแนวสันจมูก
8. **Forehead Luminance Ratio (F8):** สัดส่วนความสว่างของหน้าผากเปรียบเทียบกับความสว่างรวม
9. **Horizontal Edge Gradient (F9):** ทิศทางการกระจายตัวของขอบเงาในแนวนอน
10. **Peripheral Harmonic Variance (F10):** ความแปรปรวนของแสงขอบภาพรอบนอก

---

## ⚙️ ขั้นตอนวิธี Machine Learning (K-Means Algorithm)

1. **Feature Extraction:** สกัดเวกเตอร์คุณลักษณะ 10 มิติจากภาพถ่ายนักศึกษาทั้ง 18 ภาพ
2. **Feature Normalization (Z-Score Standardization):** ปรับข้อมูลทุกมิติให้อยู่ในสเกลเดียวกัน ($\mu = 0, \sigma = 1$)
   $$Z = \frac{X - \mu}{\sigma}$$
3. **Informed Centroid Seeding:** กำหนดจุดศูนย์กลางเริ่มต้น (Centroids) จากตัวแทนกลุ่ม 4 คน (`Pae`, `Memi`, `Saimai`, `Supachok`) เพื่อป้องกันปัญหา Local Minima และให้ผลลัพธ์คงที่
4. **Manhattan Distance (L1 Norm):** คำนวณระยะห่างระหว่างจุดข้อมูลใบหน้าและ Centroid
   $$D(X, C) = \sum_{i=1}^{10} |X_i - C_i|$$
   ซึ่งทนทานต่อ Outliers และการแปรปรวนของแสงเงาได้ดีกว่า Euclidean Distance
5. **Iterative Assignment & Update:** จัดกลุ่มข้อมูลและอัปเดต Centroid ใหม่จนกว่ากลุ่มจะคงที่และลู่เข้าสู่จุดสมดุล (Convergence)

## 🚀 วิธีการติดตั้งและการรันโปรแกรม

### 1. ติดตั้ง Dependencies
```bash
pip install opencv-python numpy matplotlib
```

### 2. รันการจัดกลุ่ม K-Means
```bash
python FaceCluster.py
```
> ระบบจะสกัดคุณลักษณะ, ดำเนินการจัดกลุ่ม K-Means, สรุปรายชื่อสมาชิกในแต่ละสายอาชีพลงบน Terminal และแสดงตารางภาพใบหน้า 4 กลุ่มพร้อมคำอธิบายบุคลิกภาพอย่างสวยงาม

### 3. รันระบบ Real-time Face Recognition
```bash
python FaceRecognize.py
```
> ระบบจะเปิดกล้องเว็บแคม ตรวจจับใบหน้าสด คำนวณหาระยะห่างที่ใกล้ที่สุด และแสดงชื่อบุคคล, สายอาชีพที่สังกัด, พร้อมแถบระดับความมั่นใจ (Confidence Bar)
