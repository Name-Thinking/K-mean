## 💡 3. เหตุผลทางคณิตศาสตร์และทฤษฎี (เตรียมตอบอาจารย์)

### ทำไมใช้ Manhattan Distance (L1) แทน Euclidean (L2)?
* **สูตร:** $\text{Distance} = \sum |x_i - c_i|$
* **เหตุผล:** ข้อมูลกายภาพที่เราสนใจ (ใส่แว่น/ไม่ใส่, มีหน้าม้า/ไม่มี) เป็นคุณลักษณะแบบแยกส่วนชัดเจน (Discrete/Binary) การใช้ **L1 Distance** จะไม่ยกกำลังสอง ทำให้ไม่ถูกรบกวนจากค่าสุดโต่ง (Outliers) และแบ่งขอบเขตแต่ละกลุ่มได้แม่นยำกว่า

### ค่า Silhouette Score = 0.956 หมายถึงอะไร?
* ค่า Silhouette Score มีค่าอยู่ระหว่าง $-1$ ถึง $+1$
* ค่า **0.956** แสดงว่า:
  1. สมาชิกทุกคนอยู่ใกล้จุดกึ่งกลาง (Centroid) ของกลุ่มตัวเองมาก
  2. สมาชิกอยู่ห่างจากกลุ่มอื่นมากที่สุด ไม่มีการเกาะก้ำกึ่งระหว่างขอบกลุ่ม

## 🚀 4. วิธีการเปิดใช้งานระบบ (Quick Start)

### วิธีที่ 1: เปิดผ่านหน้าต่างเมนูหลัก (แนะนำ)
```bash
python ใบหน้ารวม.py/main.py
```
* จะมีหน้าต่าง Desktop UI แสดงสรุป 4 กลุ่ม พร้อม 3 ปุ่มให้กดใช้งาน:
  1. **เริ่มจัดกลุ่มและแสดงหน้าต่างกราฟิก (GUI Interactive)**
  2. **ประมวลผลด่วนและบันทึกภาพ (Export Headless)**
  3. **เปิดดูไฟล์ภาพผลลัพธ์ (cluster_result.png)**

### วิธีที่ 2: รันประมวลผลจัดกลุ่มโดยตรง
```bash
# รันพร้อมเปิดหน้าต่างภาพ
python ใบหน้ารวม.py/FaceCluster.py

# รันประมวลผลเซฟภาพอย่างเดียว (ไม่เปิดหน้าต่าง)
python ใบหน้ารวม.py/FaceCluster.py --no-show
```
