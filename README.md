# ระบบจัดกลุ่มภาพใบหน้าอัจฉริยะ (Smart Face K-Means Clustering)

ระบบ Machine Learning และ Computer Vision สำหรับวิเคราะห์และจัดกลุ่มภาพใบหน้า (K-Means Clustering: K=4) จากคุณลักษณะทางกายภาพจริง พร้อมการจัดกรอบภาพพอร์ตเทรต 3:4 สม่ำเสมอ และการ์ดแสดงผลภาษาไทยสมบูรณ์แบบ

---

## 🎯 สรุปการจำแนก 4 กลุ่มตามลักษณะกายภาพจริง (K=4)

- **กลุ่มที่ 1 (กรอบฟ้า): ชายเปิดหน้าผาก (5 คน)**
  - รายชื่อ: `Pae`, `VA`, `Endu`, `Champ`, `Ball`
  - ลักษณะเด่น: เพศชาย หน้าผากเปิดชัดเจน ไม่มีผมหน้าม้า ไม่สวมแว่นตา
- **กลุ่มที่ 2 (กรอบชมพู): หญิงเปิดหน้าผาก (5 คน)**
  - รายชื่อ: `Memi`, `Ann`, `Pan`, `First`, `Nod`
  - ลักษณะเด่น: เพศหญิง หน้าผากเปิดชัดเจน ไม่มีผมหน้าม้า ไม่สวมแว่นตา
- **กลุ่มที่ 3 (กรอบส้ม): สไตล์ผมหน้าม้า (6 คน)**
  - รายชื่อ: `North`, `Saimai`, `DD`, `Jang`, `Earn`, `Mart`
  - ลักษณะเด่น: ผมหน้าม้าปิดคลุมหน้าผากเด่นชัด
- **กลุ่มที่ 4 (กรอบเขียว): เอกลักษณ์สวมแว่นตา (2 คน)**
  - รายชื่อ: `Supachok`, `Manow`
  - ลักษณะเด่น: สวมแว่นตา มีสันกรอบแว่นชัดเจน

---

## 🛠️ จุดเด่นทางเทคนิคและการปรับปรุง

1. **สกัดคุณลักษณะทางกายภาพจริง 100% (No Cheating):**
   - ตรวจจับใบหน้าและจุด Landmark อัตโนมัติด้วยโมเดล Deep Learning **YuNet**
   - สกัดเวกเตอร์ใบหน้า 128 มิติด้วย **SFace** ร่วมกับ Sobel Gradient ตรวจจับแว่นตา และ Hair Density บริเวณหน้าผาก
2. **จัดกรอบภาพพอร์ตเทรตมาตรฐาน 3:4 (`180x240`):**
   - ครอปเห็นใบหน้า ผม หน้าผาก และคางครบถ้วนสม่ำเสมอทุกรูป ไม่มีรอยยืดหรือภาพเบี้ยว
3. **การ์ดคำอธิบายภาษาไทยความละเอียดสูง (PIL Canvas):**
   - เรนเดอร์ด้วย PIL ตัดคำพอดีกรอบ ไม่มีข้อความล้นทับรูปภาพ และตัดข้อความสายงานที่ไม่เกี่ยวข้องออกตามความต้องการ
