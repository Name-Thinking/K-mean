# ระบบตรวจจับ จดจำ และจัดกลุ่มใบหน้าลูกค้าอัจฉริยะ (Smart Face Access & K-Means Clustering)

ระบบ Machine Learning และ Computer Vision สำหรับจัดกลุ่มใบหน้าตามสายอาชีพ (K-Means Clustering) และสแกนใบหน้าเข้าใช้งานแบบ Real-time ผ่านกล้องเว็บแคม โดยออกแบบใหม่ให้ลูกค้าเข้าใช้งานได้ง่ายและแม่นยำสูง พร้อมการจัดภาพและกราฟิกแสดงผลที่สมบูรณ์

---

## 🛠️ สรุปการแก้จุดโหว่ ยกระดับความแม่นยำ และแก้รูปให้สมบูรณ์

1. **ตรวจจับใบหน้าอัตโนมัติทั่วหน้าจอ (Auto Face Detection — YuNet):**
   - **แก้จุดโหว่เดิม:** ยกเลิกกรอบสี่เหลี่ยมสีแดงตายตัว `(250, 120, 390, 300)` ที่บังคับให้ลูกค้าต้องเกร็งหน้าให้ตรงช่อง
   - **ระบบใหม่:** ใช้โมเดล **YuNet** ตรวจจับใบหน้าและจุด Landmark 5 จุด (ตา จมูก ปาก) แบบ Real-time ไม่ว่าลูกค้าจะยืนใกล้ ไกล เอียง หรือขยับตัวไปมุมไหนของหน้าจอ

2. **ความแม่นยำระดับ Deep Learning Embeddings (SFace 128-D + Cosine Similarity):**
   - **แก้จุดโหว่เดิม:** ยกเลิกการใช้ค่าความสว่างพิกเซลเฉลี่ย (ซึ่งเพี้ยนทันทีเมื่อแสงห้องเปลี่ยน)
   - **ระบบใหม่:** ใช้โมเดล **SFace** สกัดเวกเตอร์ใบหน้า 128 มิติ และเปรียบเทียบด้วย Cosine Similarity ร่วมกับ **Dual-Gate Threshold** (เกณฑ์ขั้นต่ำ `0.38` + Margin ระหว่างอันดับ 1 กับ 2 + Temporal Voting 6 เฟรม)

3. **ระบบคัดกรองคุณภาพและกันจุดโหว่ (Quality Gate & Check-in Audit):**
   - ตรวจสอบขนาดใบหน้า ความคมชัด (Anti-blur ด้วย Laplacian Variance) ความสว่าง และมุมมองหน้าตรงก่อนสแกน/บันทึก
   - คัดกรองบุคคลที่ยังไม่ได้ลงทะเบียนเป็น `Unknown` พร้อมปุ่มลงทะเบียนด่วนและบันทึกประวัติการเข้าใช้งานอัตโนมัติลง `logs/checkin_log.csv`

4. **ลงทะเบียนลูกค้าใหม่ได้ทันที (One-Key Instant Enrollment):**
   - **แก้จุดโหว่เดิม:** ยกเลิกการ Hardcode ชื่อ `'parinya'` และปัญหาที่บันทึกไฟล์ลงคนละโฟลเดอร์กับตัวสแกน
   - **ระบบใหม่:** กดปุ่ม **`R`** ในหน้าสแกน (หรือเปิด `FaceTrain.py`) กรอกชื่อลูกค้า รองรับภาษาไทย แล้วระบบจะถ่ายภาพใบหน้าที่ชัดเจนให้อัตโนมัติ 5 มุมภายใน 2 วินาที พร้อมใช้งานได้ทันทีโดยไม่ต้องรีสตาร์ทโปรแกรม

5. **จัดกลุ่ม K-Means จากคุณลักษณะจริง 100% และแก้รูปกราฟิกให้สมบูรณ์ (`FaceCluster.py`):**
   - **แก้จุดโหว่เดิม:** ลบ `_SPECTRAL_MATRIX` (ค่าแฮชลวงโลก) ออกทั้งหมด และแก้ปัญหากราฟิกที่ข้อความการ์ดฝั่งซ้ายล้นทับรูปใบหน้า รวมถึงขนาดภาพครอปที่ไม่เท่ากันและรอยยืดขอบ
   - **ระบบใหม่:** ใช้ `Smart Portrait Auto-Framer` ปรับกรอบภาพพอร์ตเทรต 3:4 (`180x240`) ให้เห็นใบหน้า ผม หน้าผาก และคางครบถ้วนสม่ำเสมอทุกรูป เรนเดอร์การ์ดภาษาไทยด้วย PIL ตัดบรรทัดพอดีกรอบ 100% พร้อมสกัดคุณลักษณะกายภาพจริง (แว่นตา, ผมหน้าม้า, โครงสร้างใบหน้า Out-of-Fold Gender Axis)

6. **รองรับ Path ภาษาไทยบน Windows และค้นหาโฟลเดอร์ภาพอัตโนมัติ:**
   - แก้ปัญหา OpenCV DNN อ่านไฟล์ ONNX จากโฟลเดอร์ภาษาไทยไม่ได้ด้วย ASCII-safe Path Resolver (`GetShortPathNameW` + Temp Cache)
   - ดาวน์โหลดโมเดลแบบ Atomic พร้อมแสดงแถบเปอร์เซ็นต์ความคืบหน้า และค้นหาโมเดล/โฟลเดอร์ `ML_Data_บ่าย` อัตโนมัติ

## 📁 โครงสร้างไฟล์หลัก

```text
├── ใบหน้ารวม.py/
│   ├── main.py               # หน้าเมนูหลัก (GUI Launcher 3 ปุ่ม คลิกเข้าใช้งานง่าย)
│   ├── face_engine.py        # แกนกลาง: YuNet, SFace, Portrait Framer, Quality Gate, ฐานข้อมูล, Thai HUD
│   ├── FaceRecognize.py      # ระบบสแกนหน้าเข้าใช้งาน Real-time + กด [R] ลงทะเบียนลูกค้าใหม่ทันที
│   ├── FaceTrain.py          # สตูดิโอลงทะเบียนลูกค้าใหม่แบบ Guided Auto-Capture 5 ภาพ
│   ├── FaceCluster.py        # โปรแกรมจัดกลุ่มสายอาชีพ K-Means (K=4, L1 Manhattan) + Export กราฟสมบูรณ์
│   └── test_face_system.py   # ชุดทดสอบอัตโนมัติ (ความแม่นยำ, คัดกรองคนแปลกหน้า, คุณภาพ, K-Means)
├── ML_Data_บ่าย/             # โฟลเดอร์ข้อมูลภาพตั้งต้น 18 คน (.jpg)
├── customers/                # โฟลเดอร์เก็บข้อมูลและรูปภาพลูกค้าที่ลงทะเบียนเพิ่มเติม (สร้างอัตโนมัติ)
├── models/                   # เก็บไฟล์โมเดล ONNX (ดาวน์โหลดอัตโนมัติในการรันครั้งแรก)
└── logs/                     # ประวัติการสแกนเข้าใช้งาน (checkin_log.csv)
```

## 🚀 วิธีการติดตั้งและใช้งาน

### 1. ติดตั้ง Dependencies
```bash
pip install opencv-python numpy pillow matplotlib scikit-learn
```

### 2. เปิดหน้าเมนูหลัก (แนะนำสำหรับลูกค้าและผู้ใช้งานทั่วไป)
```bash
python ใบหน้ารวม.py/main.py
```

### 3. หรือรันแยกแต่ละโหมดโดยตรง
- **สแกนใบหน้าเข้าใช้งาน (Check-in):**
  ```bash
  python ใบหน้ารวม.py/FaceRecognize.py
  ```
  > **คีย์ลัดระหว่างสแกน:** `[R]` ลงทะเบียนลูกค้าใหม่ทันที • `[D]` เปิด/ปิด Top-3 คะแนน • `[U]` รีโหลดฐานข้อมูล • `[Q]` ออก
- **ลงทะเบียนลูกค้าใหม่:**
  ```bash
  python ใบหน้ารวม.py/FaceTrain.py
  ```
- **จัดกลุ่มสายอาชีพ K-Means (K=4):**
  ```bash
  python ใบหน้ารวม.py/FaceCluster.py
  ```

### 4. รันชุดทดสอบความแม่นยำและความปลอดภัย
```bash
python ใบหน้ารวม.py/test_face_system.py
```
