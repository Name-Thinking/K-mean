# โครงงานจัดกลุ่มภาพใบหน้าด้วย K-Means Clustering (Face Clustering & Recognition)

โครงงานนี้พัฒนาด้วยภาษา Python เพื่อทำการจัดกลุ่มภาพถ่ายใบหน้าของนักศึกษาจำนวน 18 คน ออกเป็น 4 กลุ่มตามคุณลักษณะทางกายภาพที่เด่นชัด (เช่น เพศ, ผมหน้าม้า, และการสวมแว่นตา) โดยประยุกต์ใช้แนวคิด **Machine Learning (Unsupervised Learning)** ด้วยอัลกอริทึม **K-Means Clustering** ร่วมกับการคำนวณระยะห่างแบบ **Manhattan Distance (L1 Norm)** และระบบจดจำใบหน้าแบบ Real-time ผ่านกล้องเว็บแคม

---

## 👥 สรุปผลการจัดกลุ่ม 4 กลุ่ม (K = 4, รวม 18 คน)

| กลุ่ม (Cluster) | จำนวน | รายชื่อสมาชิก | คุณลักษณะเด่นร่วม |
|---|---|---|---|
| **Group 1: ชาย-เปิดหน้าผาก** | 4 คน | `Pae`, `Endu`, `Champ`, `Ball` | เพศชาย • เปิดหน้าผาก • ไม่สวมแว่นตา |
| **Group 2: หญิง-เปิดหน้าผาก** | 5 คน | `Memi`, `Pan`, `First`, `Nod`, `Earn` | เพศหญิง • เปิดหน้าผาก • ไม่สวมแว่นตา |
| **Group 3: รวมชาย+หญิง (ผมหน้าม้า)** | 7 คน | `VA`, `North`, `Jang`, `Mart`, `Ann`, `Saimai`, `DD` | เพศชาย + หญิง • มีผมหน้าม้าปิดหน้าผาก • ไม่สวมแว่นตา |
| **Group 4: บุคคลใส่แว่นตา** | 2 คน | `Supachok [M]`, `Manow [F]` | สวมใส่แว่นตา (ทั้งเพศชายและหญิง) |

---

## 🧬 10 คุณลักษณะเด่นของใบหน้า (Feature Extraction)

เพื่อให้โมเดลสามารถแยกแยะกลุ่มได้อย่างแม่นยำ ได้ทำการสกัดเวกเตอร์คุณลักษณะ 10 มิติจากแต่ละภาพ:

1. **Glasses Darkness (F1):** วัดความมืดเฉลี่ยบริเวณดวงตา (ตรวจจับกรอบแว่น)
2. **Forehead Brightness (F2):** วัดความสว่างเฉลี่ยบริเวณหน้าผากด้านบน (แยกผมหน้าม้ากับหน้าผากเปิด)
3. **Forehead Edge Density (F3):** วัดความหนาแน่นขอบเส้นผมบนหน้าผากด้วย Sobel Edge Detection
4. **Eyebrow Density (F4):** วัดความหนาแน่นและความเข้มของแนวคิ้ว
5. **Jawline / Chin Intensity (F5):** วัดโครงสร้างแนวกรามและคาง (สะท้อนสรีระของเพศชาย/หญิง)
6. **Skin Tone Luminance (F6):** ค่าความสว่างเฉลี่ยของผิวหน้า
7. **Bangs Boundary Sharpness (F7):** วัดความคมชัดของรอยต่อเส้นผมหน้าม้า
8. **Eye-Bridge Contrast (F8):** วัดค่าความต่างคอนทราสต์ที่สันจมูกและดั้งแว่นตา
9. **Left-Right Symmetry (F9):** วัดความสมมาตรของใบหน้าซีกซ้ายและขวา
10. **Horizontal Gradient (F10):** ความแปรปรวนของการกระจายแสงในแนวนอน

---

## ⚙️ ขั้นตอนวิธี Machine Learning (K-Means Algorithm)

1. **Feature Extraction:** ดึงค่าเวกเตอร์คุณลักษณะ 10 มิติจากภาพทั้ง 18 ภาพ
2. **Feature Normalization (Z-Score Standardization):** ปรับสเกลทุกฟีเจอร์ให้อยู่ในมาตรฐานเดียวกัน ($\mu = 0, \sigma = 1$) ป้องกันฟีเจอร์ที่มีช่วงค่ากว้างมีอิทธิพลเกินไป
3. **Feature Weighting:** ถ่วงน้ำหนักฟีเจอร์ที่สำคัญ เช่น น้ำหนักของแว่นตา ($w=2.8$) และหน้าผาก/ผมหน้าม้า ($w=2.4$)
4. **Informed Centroid Seeding:** กำหนดจุดศูนย์กลางเริ่มต้น (Centroids) จากตัวแทนกลุ่ม 4 คน (`Pae`, `Memi`, `Saimai`, `Supachok`)
5. **Manhattan Distance (L1 Norm):** คำนวณระยะห่างระหว่างจุดข้อมูลและ Centroid
   $$D(X, C) = \sum_{i=1}^{10} |X_i - C_i|$$
   ซึ่งทนทานต่อ Outliers และความเบี่ยงเบนของแสงเงาได้ดีกว่า Euclidean Distance
6. **Iterative Assignment & Update:** จัดกลุ่มข้อมูลและอัปเดต Centroid ใหม่จนกว่ากลุ่มจะคงที่ (Converged)

## 🚀 วิธีการติดตั้งและการรันโปรแกรม

### 1. ติดตั้ง Dependencies
```bash
pip install opencv-python numpy matplotlib
```

### 2. รันการจัดกลุ่ม K-Means
```bash
python FaceCluster.py
```
> ระบบจะคำนวณ K-Means, แสดง Log สรุปจำนวนสมาชิกแต่ละกลุ่มในคอนโซล และเปิดหน้าต่างกราฟตารางภาพใบหน้า 4 กลุ่มพร้อมคำอธิบายลักษณะเด่น

### 3. รันระบบ Real-time Face Recognition
```bash
python FaceRecognize.py
```
> ระบบจะเปิดกล้องเว็บแคม ตรวจจับใบหน้าในกรอบสี่เหลี่ยม คำนวณหาบุคคลที่ใกล้เคียงที่สุด พร้อมแสดงเพศ, กลุ่มที่สังกัด และแถบระดับความมั่นใจ (Confidence Bar)
